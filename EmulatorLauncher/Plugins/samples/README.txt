RetroNexus システム画面のプラグイン: サンプル

このフォルダのファイルは、プラグインの書き方を示すサンプルです。値は、PC の一時フォルダ(%TEMP%\retronexus-sample-*.txt)に
保存するだけで、機器の設定は変更しません。

サンプルの一覧:
  サンプル: 時計 / ランダム ........ 値を表示するだけの項目(stat)。時計は常駐型(stream)の例
  サンプル: スライダー ............. 左右で値を変える項目
  サンプル: オンオフ / 選択肢 ...... 押して切り替える項目
  サンプル: 押した回数 / 失敗するボタン ... ボタン(失敗したときは揺れて知らせます)
  サンプル: TDP(ダミー) ............ TDP を選ぶ項目の例(実際には何も変更しません)
  サンプル: CPU温度 ................ CPU 温度の表示の例(OS 標準の機能で取れる機器のみ値が出ます)

使いかた:
  1. 設定 → システム設定 → 「システム項目の編集」を開く。
  2. 「プラグイン: ...」に出ているサンプルから、使いたいものを選んで有効にする。
  3. システム画面(右から出るパネル)に、項目が追加される。

不要なら、この samples フォルダごと削除して構いません。
json の書き方は、1つ上の Plugins フォルダの PLUGINS.md を参照してください。
注意: プラグインは PC で任意のコマンドを実行できます。信頼できるものだけを置いてください。
