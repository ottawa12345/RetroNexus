# システム画面のプラグイン

RetroNexus のシステム画面(右から出るパネル)には、**外部のコマンドを起動するだけ**の項目を、プラグインとして追加できます。
プラグインが行うのは「コマンドを実行して、その結果を表示する」ことだけです。RetroNexus 自身は、設定の変更や機器の制御を行いません。

> **注意: プラグインは、あなたの PC で任意のコマンドを実行できます。** 信頼できる配布元のものだけを `Plugins` フォルダに置いてください。
> プラグインは最初は**無効**で、ご自身で有効にしたものだけが動きます。

## 使いかた

0. まず試したいときは、配布物の `Plugins\samples` にサンプルがあります(表示・ボタン・オンオフ・選択・スライダーの例)。手順2へ進んで有効にすると、動きを確認できます。不要なら、フォルダごと削除して構いません。
1. 実行ファイル(`RetroNexus.exe`)のフォルダに `Plugins` フォルダを作り、プラグインの json ファイルを置きます(サブフォルダに分けても構いません)。
2. **設定 → システム設定 → システム項目の編集** を開きます。一覧に「プラグイン: 名前」として出るので、使いたいものを選びます。
3. **設定 → システム設定 → システム項目の並び替え** で、並びを変えられます。内蔵の項目もプラグインも同じ一覧です。**空白**を足して、行の途中に隙間を空けることもできます(X で追加、Y で削除)。右側のプレビューで、システム画面での並びを確認できます。

## 動作のルール

- パネルは**横6マス**に詰めて並びます。タイルは2マス、スライダーは1行ぶん、プラグインは `width`×2マスです。入りきらないときは、スクロールします。
- `status` のコマンドが成功しない(起動できない、時間切れ、終了コードが0以外、JSON が不正など)プラグインは、その環境では使えないものとして**表示されません**。一度表示されたものも、3回続けて失敗すると隠れます。
- コマンドは、**パネルを開いている間だけ**動きます。シェルは通さず、`exe` と `args` を直接起動します。出力は 64KB までです。
- 時間切れは、既定で `status` が3秒、`action` が10秒です(`timeoutSec` で変えられます)。
- 次の文字列は、実行時に置き換わります。`{value}`(`action` へ渡す値)、`{pluginDir}`(json のあるフォルダ)、`{appDir}`(アプリのフォルダ)。作業フォルダの既定は、json のあるフォルダです。
- ゲーム中にパネルを開いたとき、`"allowInGame": false` の項目は、グレーになって操作できません。

## json の形式(`schema` は 1)

json には `//` で始まる行のコメントを書けます(サンプルでは、書き換える箇所の説明に使っています)。未対応のキーは無視されます。

| キー | 内容 |
|---|---|
| `schema` | `1` |
| `id` | 半角の小文字・数字・`-`・`_`。重複したときは、2つ目以降は無視されます |
| `name` | 表示名 |
| `display` | `stat`(表示だけ) / `tile`(押す) / `slider`(左右で値を変える) |
| `width` | 1〜3(省略時: slider=3、ほかは1)。`stat` と `tile` は、2/4/6マスになります |
| `order` | プラグイン同士の既定の並び(小さいほど先) |
| `icon` | Segoe Fluent Icons の文字、または `"E767"` のような16進コード |
| `status` | `{ "exe", "args":[], "workingDir", "timeoutSec", "intervalSec", "stream" }`。`stream: true` にすると常駐型になります(下の「常駐型の status」を参照)。`intervalSec` が0か省略なら、「パネルを開いたとき」と「操作のあと」だけ取得します。1以上なら、開いている間その秒数ごとに取得します(毎回コマンドを起動するので、**5秒以下の間隔にしたいときは、`intervalSec` ではなく常駐型(`stream`)を使ってください**) |
| `action` | `status` と同じ形式(`intervalSec` は使いません)。`{value}` に、選んだ値が入ります |
| `options` | `{ "type":"range", "min", "max", "step", "unit" }`(スライダー)<br>`{ "type":"choice", "items":[{"value","label"}] }`(選択)<br>`{ "type":"toggle" }`(オン/オフ。`{value}` は `on` / `off`)<br>`tile` で `options` が無いものは、ボタンになります |
| `format` | 表示する文字。`{value}` と `{detail}` が置き換わります |
| `bar` | `stat` に出すバー。`{ "min":0, "max":100 }` |
| `allowInGame` | ゲーム中も操作できるか(既定は `true`) |

## コマンドが返す JSON

コマンドは、標準出力に次の JSON を返します。

```json
{ "success": true, "value": 15, "detail": "任意の補足", "message": "失敗したときの説明" }
```

- `value` は、文字列・数値・真偽のどれでも構いません(文字列として扱います)。
- `status` は、必ず JSON を返します。
- `action` は、「終了コード0で、何も出力しない」でも成功になります。

### 常駐型の status(`"stream": true`)

更新の間隔が**5秒以下**になるもの(時計など)は、`intervalSec` で毎回コマンドを起動せず、常駐型にしてください。コマンドの起動は、1回あたりそれなりに重い処理です(特に PowerShell)。目安は次のとおりです。

| 更新の間隔 | 使うもの |
|---|---|
| 5秒以下 | 常駐型(`stream: true`) |
| 5秒より長い | `intervalSec`(または、開いたときだけ取得) |

- パネルを開いたときにコマンドを**1回だけ**起動し、パネルを開いている間は動かし続けます。
- コマンドは、好きなタイミングで標準出力に**1行につき1つの JSON**(上と同じ形式)を書き出します。1行届くたびに、表示が更新されます。出力のたびに必ず改行し、バッファを流してください。
- パネルを閉じるとき、アプリはコマンドの**標準入力を閉じます**。標準入力が終わった(読み取りが空になった)ら、コマンドは自分で終了してください。1.5秒待っても終わらないときは、強制終了されます。アプリが突然終了したときも、同じく標準入力が閉じます。
- 最初の1行が `timeoutSec`(省略時は5秒)以内に出ないと、失敗として扱います。常駐型では、`timeoutSec` は「最初の1行が出るまでの時間」だけに使い、最初の1行が出たあとの時間切れはありません。最初の出力が遅いコマンドは、長めに指定してください。
- コマンドが途中で終了したときは、5秒後に起動し直します。3回続けて失敗すると、パネルを閉じるまであきらめ、項目は隠れます。
- `stream` を指定したときは、`intervalSec` は無視します。`action` は、今までどおり操作のたびに起動します。

PowerShell での例(1秒ごとに時刻を出し、標準入力が閉じたら終了):

```powershell
$reader = [Console]::In.ReadLineAsync()
while ($true) {
    [Console]::Out.WriteLine((@{ success = $true; value = (Get-Date).ToString('HH:mm:ss') } | ConvertTo-Json -Compress))
    [Console]::Out.Flush()
    if ($reader.Wait(1000)) {                       # 1秒待つ。その間に標準入力が動いたら
        if ($null -eq $reader.Result) { break }      # 閉じられた → 終了
        $reader = [Console]::In.ReadLineAsync()
    }
}
```

### 種類ごとの動き

- **stat**: `value` を `format` で整形して大きく表示し、`detail` を小さく表示します。`bar` があれば、バーも出ます。フォーカスは乗りません。
- **slider**: `value` を現在値に反映します。左右で調整し、止まってから 0.4 秒後に、最後の値で `action` を1回だけ実行します(パネルを閉じるときは、残りをすぐに実行します)。
- **tile(toggle)**: `value` が `on` / `true` / `1` ならオン表示です。押すとすぐに反転し、`action` が失敗したら元に戻します。
- **tile(choice)**: `value` に一致する `label` を補足として表示します。押すと選択画面が開き、選んだ `value` で `action` を実行します。
- **tile(ボタン)**: 押すと `action` を実行します。失敗したときは、揺れて知らせます。
- `action` のあとは、`status` を取り直します。失敗は、`data\log\app_*.log` に記録されます。

## 例

GPU 温度を表示するだけの項目(1/3幅):

```json
{ "schema":1, "id":"gpu-temp", "name":"GPU温度", "display":"stat", "width":1, "order":10, "icon":"E9CA",
  "status": { "exe":"powershell.exe", "args":["-NoProfile","-File","{pluginDir}\\gpu-temp.ps1"], "intervalSec":2 },
  "format":"{value}℃", "bar": { "min":0, "max":100 } }
```

左右で値を変えるスライダー:

```json
{ "schema":1, "id":"fan", "name":"ファン", "display":"slider", "order":20, "icon":"E9CA",
  "status": { "exe":"C:\\Tools\\fanctl.exe", "args":["get"] },
  "action": { "exe":"C:\\Tools\\fanctl.exe", "args":["set","{value}"] },
  "options": { "type":"range", "min":0, "max":100, "step":10, "unit":"%" } }
```

選択肢から選ぶタイル:

```json
{ "schema":1, "id":"tdp", "name":"TDP", "display":"tile", "width":1, "order":30, "allowInGame":true,
  "status": { "exe":"C:\\Tools\\tdp.exe", "args":["get"], "intervalSec":5 },
  "action": { "exe":"C:\\Tools\\tdp.exe", "args":["set","{value}"] },
  "options": { "type":"choice", "items":[ {"value":"8","label":"8W"}, {"value":"15","label":"15W"}, {"value":"25","label":"25W"} ] },
  "format":"{value}" }
```

## 管理者権限が必要なコマンドについて

RetroNexus は、通常の権限で動きます。TDP やファンの制御のように、管理者権限が必要なコマンドは、そのままでは実行できません。
RetroNexus を管理者として起動するか、別途ご自身で用意した仕組み(管理者権限で動くサービスなど)を経由してください。セキュリティ上の理由から、RetroNexus が管理者権限を自動で取得することはありません。
