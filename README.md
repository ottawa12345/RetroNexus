# RetroNexus

Windows 向けの、ゲームパッドで操作するレトロゲームランチャーです。テレビの前でコントローラーだけで、機種の選択からゲームの起動・中断・再開まで行えます。
エミュレーション自体は [libretro](https://www.libretro.com/) のコアが行います。RetroNexus はそれを呼び出す「フロントエンド」です。

下記ブログにて詳細を記載しております。
https://note.com/ottawa123/n/n68e821463bdc?app_launch=false

## 目指したこと

- エミュレーターごとの設定を、個別にしなくてよいこと。コアをアプリ内で入れて、ROM のフォルダを登録するだけで遊べます。
- コントローラー1つで、機種の選択から、起動、中断、再開まで完結すること。
- ゲームの認識と検索を、手元のデータで素早く行うこと。1本ごとにネットへ問い合わせず、同梱のデータベースで照合します。

## 特長

- **ゲームパッド中心の操作**: メニューもゲーム中の中断メニューも、コントローラーだけで操作できます。キーボード、マウス、タッチでも、メニューを操作できます(ゲーム中は、ゲームコントローラーとキーボードです)。
- **40 機種以上に対応**: 機種ごとにコアを割り当てられます(下の一覧を参照)。
- **ROM の自動認識**: ROM フォルダを登録すると、libretro-database の RDB で CRC・シリアル・名前から認識し、パッケージ画像を取得します。
- **日本語名の表示**: 機種ごとの日本語名・読み・ジャンル・紹介文を、自作データから表示します。
- **コレクション**: お気に入りなどのコレクションを作って、機種をまたいで並べられます。
- **便利なプレイ機能**: セーブステート、巻き戻し、早送り、中断と再開、ディスク入れ替え、プレイ時間の記録に対応しています。
- **コアの管理画面**: コアの導入と削除、コアごとの設定を、アプリ内で行えます。
- **外部アプリの起動**: エミュレーターなど、外部のプログラムをランチャーとして登録して起動できます。
- **システム画面**: 音量・明るさ・Wi-Fi・Bluetooth・電源モード・CPU/メモリの使用率などを、ゲーム中にも右のパネルから確認・操作できます(その機器で使えない項目は、自動で表示されません)。
- **プラグインで項目を追加**: 外部のコマンドを呼び出すだけの項目(TDP やファンの表示・操作など)を、json ファイルで足せます。詳しくは [PLUGINS.md](PLUGINS.md) を参照してください。配布物の `Plugins\samples` に、動作を試せるサンプルが入っています(最初は無効です。不要なら、フォルダごと削除して構いません)。
- **システム項目の並び替え**: 並びを自由に変えたり、空白を入れて隙間を空けたりできます。右のプレビューで、パネルでの並びを確認できます。

## 動作環境

- Windows 10 (1809) 以降、64 ビット(x64)(.NET などのランタイムを別に入れる必要はありません)
- ゲームパッド(SDL3 が認識するもの)

## 動作確認した機種

- **開発機**: HX100G
- **GPD WIN MAX 2**(6800U 版)

上記以外の機種でも動くと思いますが、確認はしていません。システム画面の項目は、その機器で使えないものは表示されません(たとえば、デスクトップ PC にはバッテリーや画面の明るさがありません)。

## 使い方

1. 配布ページのリンクから zip をダウンロードして、書き込みのできるフォルダ(例: `D:\RetroNexus`)に展開します。`C:\Program Files` の中には置かないでください(設定を保存できません)。
2. `RetroNexus.exe` を起動します。
3. **設定 → ゲームフォルダ管理** で、ROM を置いたフォルダと機種を登録します。その機種の既定のコアが未導入なら、自動でダウンロードして導入します(外部アプリを使う機種を除く)。スキャンが終わると、ゲームが一覧に並びます。
4. コアの入れ替えや削除、別のコアの追加は、**設定 → コア管理** で行えます。
5. 機種を選び、ゲームを選んで起動します。ゲーム中は、メニューボタンで中断メニューを開けます。

### 用意していただくもの

- **ROM / ディスクイメージ**: 同梱していません。ご自身が正当に所有しているものを使ってください。
- **BIOS / ファームウェア**: 同梱も自動ダウンロードもしていません。必要な機種(セガサターン、PlayStation、PC エンジン CD、FM TOWNS など)は、各コアが要求するファイルを、ご自身で所定のフォルダに置いてください。

### 機種の画像(任意)

機種選択の画面に出すアイコンとロゴの画像を変更することができます。

- `Images\Console` : 機種のアイコン
- `Images\Console\Dark` : 機種のアイコン
- `Images\Logo` : 機種のロゴ
- `Images\System` : コレクション用のアイコン

ファイル名は、`Consoles.json` の `iconPath` と `logoPath` に書かれているものと同じにしてください(例: `Images\Console\fc.png`)。画像がなくても、動作には影響しません。

## 注意事項

- **プラグインは、PC で任意のコマンドを実行できます。** 信頼できる配布元のものだけを `Plugins` フォルダに置いてください。最初は無効で、ご自身で有効にしたものだけが動きます([PLUGINS.md](PLUGINS.md))。

- 本ソフトウェアは、ROM や BIOS の入手・配布を行うものではなく、そのような行為を支援するものでもありません。
- コアは RetroNexus の一部ではなく、それぞれの開発者が配布する別のプログラムです。コアのライセンスは、各コアごとに異なります。インストールするコアのライセンスを、必ず確認してください。
- ゲームフォルダを登録すると、その機種の既定のコアを、libretro の公式サイト(buildbot.libretro.com)から自動でダウンロードします。コアを同梱していないのは、そのためです。不要なコアは、「設定 → コア管理」で削除できます。
- ゲームのタイトル名や画像の権利は、それぞれの権利者に帰属します。
- コアは随時更新されます。更新後に動作しなくなった場合は、コアを入れ直してみてください。
- RC版のため、セーブデータなどの保存形式が、正式版までに変わる可能性があります。大切なデータはバックアップしてください。
- 新しい版は、配布ページから手動で入れ替えてください(アプリは、新しい版の有無を確認しません)。
- 実行ファイルにコード署名がないため、初回の起動時に、Windows の SmartScreen が警告を出すことがあります。その場合は、「詳細情報」→「実行」を選んでください。
- 本ソフトウェアは無保証で提供されます。使用によって生じたいかなる損害についても、作者は責任を負いません。

## 不具合を報告するとき

起動のたびに、動作ログを `data\log\app_日時.log` に保存しています(新しい10個を残します)。

- ログには、ROM やフォルダのパス(ユーザー名を含むことがあります)が含まれます。公開の場に貼る前に、内容を確認してください。
- ROM のスキャンの詳細は、スキャンしたフォルダの `RetroNexus\log` に、別のログとして保存されます。
- アプリが異常終了したときは、実行フォルダの `crash.log` も添付してください。
